# Bloom · Recorrido comentado

Video compuesto con seis capturas reales. Narración sintética; no es una grabación continua ni la voz de Carlos. Datos ficticios; asistente IA desactivado.

## 1. Bloom: producto real

Bloom reúne agenda, ingresos, inventario, comisiones y reportes para un salón. Carlos confirma que se usa en un negocio real. Este recorrido muestra capturas de una copia aislada, con datos inventados.

## 2. Agenda con datos ficticios

La agenda muestra tres citas de ejemplo. Los nombres de clientes, profesionales, servicios, importes y porcentajes son ficticios. La banda superior identifica el entorno de demostración.

## 3. Una operación real

Desde la interfaz se creó otra cita: Cliente Demo cuatro, Profesional Demo B, a las nueve, con cuarenta y cinco minutos de duración. La aplicación confirmó que la cita quedó creada.

## 4. Disponibilidad actualizada

Después de guardar, la disponibilidad ya no ofrece las nueve ni las nueve y media para ese profesional. En una comprobación separada del backend, otra cita superpuesta fue rechazada.

## 5. Ingresos de ejemplo

El módulo de ingresos muestra dos servicios inventados y su distribución calculada. Estas cifras sirven para explicar el funcionamiento. No son ventas ni resultados comerciales del cliente.

## 6. Pruebas y límites claros

El reporte se calcula con esos mismos movimientos ficticios. Las trece pruebas existentes del piloto de asistente pasaron con Claude simulado. Carlos atribuye el desarrollo de Bloom a Codex y ChatGPT mediante Roo Code, bajo su dirección, pruebas y correcciones.
